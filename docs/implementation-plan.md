# Lueur Cat Lounge LP 実装計画書

## ゴール
提供モック5枚の構図・余白・色・フォント・カードUI・CTAをReact + Tailwind CSSで再現した縦長LPを実装する。

## 制作方針
1. 1920x1080想定の各モックを1セクションとして、ファーストビュー / PRICE / CATS / SERVICE / RESERVEの順に配置する。
2. 余白、角丸、線、淡いローズ・ベージュ、白い光の被りをCSSレイヤーで再現する。
3. 写真素材はリファレンスの構図に合わせたプロジェクト内ラスター画像を生成し、カード・背景で使用する。
4. アイコンは透過SVG/PNG相当としてインラインSVGで実装し、背景円と組み合わせる。
5. アニメーションはフェードアップ、ホバーリフト、微細な浮遊、光のシマーを過度にならない範囲で付与する。
